# Contract — HTTP API (apps/api, FastAPI)

The API is a thin layer over the engine with the podcast vertical registered. All responses are
JSON; the OpenAPI schema generated by FastAPI is the authoritative machine contract consumed by the
frontend. Endpoints below are grouped by user story.

Conventions: `GET` is read-only (never triggers actions); mutation happens only via the action
endpoints and always records an `ActionAttempt`. Errors use standard HTTP codes with a
`{detail: ...}` body.

## Ontology explorer (US1)

- `GET /ontology/types` → list registered ObjectTypes (key, properties, links).
- `GET /ontology/types/{key}/instances?limit&offset&source&fused=` → paginated ObjectInstances;
  each includes `source_refs` and (if fused) a `resolution` summary (confidence, matcher).
- `GET /ontology/instances/{id}` → one instance with properties, `source_refs`, linked instances.
- `GET /ontology/instances/{id}/resolution` → the ResolutionDecision: `signals[]`
  (name, value, weight, contribution), `confidence`, `matcher`, rejected best candidate.
- `GET /ontology/links?from&to&type` → link instances for graph traversal in the explorer.

## Ingestion (US1, background)

- `POST /ingest/run` → enqueue an ingestion job for the registered vertical's sources
  (returns `{job_id}`). The job performs adapter → staging → resolve → object (+embeddings).
- `GET /ingest/jobs/{job_id}` → `{status, counts: {staged, fused, single_source}, errors[]}`.
- `GET /access/check` → AccessCheckResult[] per source (Principle V gate), read-only.

## Decisions & actions (US2)

- `GET /functions` → registered FunctionDefs.
- `POST /functions/{key}/run` → run a read-only function; returns its decision list. **No mutation.**
- `GET /actions` → registered ActionDefs (key, input schema, target, idempotency fields).
- `POST /actions/{key}/preview` → build the ActionAttempt in **mock** mode: logs "would do X to Y",
  returns the intended effect + idempotency key. No external change.
- `POST /actions/{key}/execute` → run in **real** mode; **requires** `{approved: true}` and (if the
  source) a passing write access check. Idempotent: a repeat with the same key →
  `skipped_idempotent`. Always records an ActionAttempt.
- `GET /actions/attempts?action&status` → audit trail of ActionAttempts (mock + real) with outcomes.

## AI agent (US3/US4)

- `POST /agent/ask` (streamed) → `{question}` → grounded answer with `citations` (object ids) and
  any `proposed_actions` (unexecuted). Never mutates. Emits a Langfuse `trace_id`.
- `POST /agent/proposals/{id}/approve` → turns a proposed action into a real ActionAttempt via the
  normal `/actions/{key}/execute` path (human-in-the-loop). Approval is explicit and audited.

## Evals (US3, also run in CI)

- `GET /evals/resolution/latest` → latest ER report: precision, recall, F1, mismatched cases,
  threshold, pass/fail.
- `POST /evals/resolution/run` → run the ER eval on the golden set (hermetic); returns the report.
  (The same entrypoint runs in CI as the gate.)

**Invariants**: `GET` and `/functions/.../run` and `/actions/.../preview` cause zero external
change; only `/actions/.../execute` with `approved:true` can; every action path writes an
ActionAttempt; agent endpoints can only *propose*, never execute.
